# ML exam example

This folder contains a synthetic dataset and a beginner-friendly machine learning exam example.

## Files

- `data/customer_churn.csv` — dataset used in the exam
- `student_exam.ipynb` — exam version with tasks and starter cells
- `solution.ipynb` — solved example with data cleaning, EDA, modeling, evaluation, and interpretation

## Goal

The dataset is designed to model a realistic churn prediction task with numerical and categorical features, missing values, and a binary target column.

The notebook sequence follows the same structure as the project exam prompt:

1. data loading and inspection
2. cleaning and preprocessing
3. exploratory data analysis
4. feature and target preparation
5. model training
6. model evaluation
7. prediction and interpretation
